## Что реализовано
В проекте проведен рефакторинг кода для демонстрации соблюдения всех пяти принципов SOLID. Каждый принцип находится в отдельном пакете:
1. **`srp`** — *Single Responsibility Principle*: разделение обработки заказа и отправки уведомлений на классы `OrderProcessor` и `NotificationService`.
2. **`ocp`** — *Open/Closed Principle*: добавление новых фигур (классов) без изменения класса `ShapeDrawer`. Используется интерфейс `Shape`.
3. **`lsp`** — *Liskov Substitution Principle*: разделение наземного транспорта и транспорта с двигателем. Класс `Bicycle` больше не наследует метод `startEngine()`.
4. **`isp`** — *Interface Segregation Principle*: разделение интерфейса `Device` на узкоспециализированные `Printer` и `Scanner`. Обычному принтеру не нужно реализовывать сканирование.
5. **`dip`** — *Dependency Inversion Principle*: класс `Computer` зависит от интерфейса `Storage`, а не от конкретного класса `HardDrive`. Благодаря этому в `Computer` можно передать как `HardDrive`, так и `SSD`.

## Команды сборки и запуска
1. Сборка проекта: `mvn clean package`
2. Запуск демонстрации: открыть класс `app.Main` в IDE и запустить метод `main()` (или через терминал `mvn exec:java -Dexec.mainClass="app.Main"`).
